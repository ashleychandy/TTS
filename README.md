# Neighbr Studios

AI-driven marketing agency portfolio built with Next.js 15, React 19, and TypeScript.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Technologies

- Next.js 15 with App Router
- React 19
- TypeScript
- CSS Modules
- Lenis (smooth scrolling)
